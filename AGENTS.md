# CHUD RACER

Chud racer (temp name) is a simple multiplayer or offline vs bots spaceship racing game, where the player manuevers quickly through a simple track with lots of geometry.

Tech stack:

* Godot 4.6
* DebugDraw3D

Please try to use simple code and solutions when possible
Use short naming schemes, eg pos_x instead of position_x. Don't use underscores in front of variable names.
